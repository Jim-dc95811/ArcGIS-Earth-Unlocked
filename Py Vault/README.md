# Py Vault

Every Python script in the ArcGIS Earth Unlocked family, in one place - copied byte for byte from the release zips you download, so you can read or compare the code without unzipping anything. When a tool gets a new release, the vault is rebuilt from the new zip (old versions stay in each repo's history).

To run a tool, download its zip from its project page - the zip has the one-click .bat launcher and everything else it needs.
