# Claude Toolbox

Working tools Claude built while maintaining the ArcGIS Earth Unlocked project family. They are kept here so a new Claude session can reuse them instead of rebuilding them. They are maintenance aids, not part of any tool Jim distributes.

All of them assume the seven repositories are cloned side by side under `/home/claude/repos/` (change the path argument if not).

| Tool | What it does | Run |
|---|---|---|
| `make_release_zip.py` | Builds a release zip in Jim's one-obvious-file layout: one top folder, files copied byte-for-byte, fixed timestamps, no `__pycache__`, refuses any `.bat` that is not CRLF. | `python3 tools/make_release_zip.py releases/Tool_v1.2.zip Tool_v1.2 Tool.bat "System Files"` |
| `linkcheck.py` | Checks every link in all seven repos: relative files, cross-repo GitHub links (including pinned commits and branches) and `#anchors`. | `python3 tools/linkcheck.py` - only known failures are three links in the preserved `legacy/Earth_Beacon_v1.0/README_original.md` |
| `check_binaries.py` | Opens every image, PDF, SVG and zip and reports damaged ones. Several uploads were found truncated at about 15 KB. | `python3 tools/check_binaries.py` |
| `tpkx_compare.py` | Compares two TPKX tile packages layer by layer: zip entries, root.json / iteminfo.json, every bundle header field, the index (missing-tile value), and every tile's bytes. Used to prove Picture World Maker's (then Rasta's) converter v0.3.0 writes exactly what mb2tpkx writes (Jim's London TPKX: 0 differences, bundles byte-identical). | `python3 tools/tpkx_compare.py reference.tpkx candidate.tpkx` |
| `md2pdf.py` | Turns a Markdown user manual into the matching printable PDF (page numbers, links rewritten to GitHub). | From the repo root: `GH_BASE=https://github.com/Jim-dc95811/<repo>/blob/main/ REPO_ROOT=. python3 <path>/md2pdf.py <manual.md> <manual.pdf> "<footer title>"` |
| `crop_screenshot.py` | Crops and resizes one of Jim's screenshots for a page (box in the displayed 2000-px coordinates). | `python3 tools/crop_screenshot.py in.png out.jpg [left top right bottom] [--width 1400]` |
| `make_gate_kmz.py` | Builds wormhole gate KMZs for EarthStick 1.3+: golden vertical rings (absolute altitude) with the gate data EarthStick reads (`gate, lat, lon, alt_m, radius_m, facing, to` or `dest_*`). | `from make_gate_kmz import gate, write_kmz` (see its docstring) |
| `build_world_gates.py` | Builds Jim's World Gates file: JAX (over JIA) -> ATL hub (Hartsfield, rings stacked by direction, 1,500 ft above the field) -> NYC, London, Paris, Rome, Tokyo, Sydney, Rio landmarks, each with an ATL return ring; red back sides. | `python3 tools/build_world_gates.py out.kmz` |
| `ARCGIS_EARTH_API.md` | Working reference for the ArcGIS Earth Automation API: every endpoint, what Jim's tools already prove, what the API cannot do (no click events), and untested ideas such as the camera picture-in-picture. | Read before any API work |
| `samples/` | `TEST_Camera_SR200_W_of_I95.kmz`: the proven live-camera object (FL511 camera 1362 in the popup, refreshes every 10 s). Unzip to read `doc.kml`. | Open in ArcGIS Earth |
| `test-rigs/` | Regression and hardening rigs for Parcel100, PointLayer, EarthStick, the PRAVE/ME tracker, Master 4, the Object Factory and Picture World Maker. | See [`test-rigs/README.md`](test-rigs/README.md) |
| `worlds/` | **Picture worlds made by code** (2026-11-06/07) - start with [`worlds/README.md`](worlds/README.md), the homework-saver guide (routes, proven numbers, pitfalls, rules, recipe). `wheres_the_firefighter/` = New Claude City + name-your-own-town hunt (one JPEG). `dark_claude_city/` = noir city engine `darkcity.py` (generated by `make_engine.py` from `_parts.py` - edit make_engine.py, never darkcity.py) + plug-ins `darkcity_architect/street/uncanny.py`; `world_tiles.py` = any size straight to TPKX. `real_sim_city/realsim.py` = fictional city on real Parcel100 lots at the real location with see-through windows (Dark Jacksonville). The .bat files are the kit launchers. | `py world_tiles.py --size 10 --spot 6` / `py realsim.py --parcels X.geojson --streetmap Y.mbtiles` |
| `make_py_vault.py` | Rebuilds `Py Vault/` (every .py/.pyw from the current release zips + README with SHA-256). Run after every release. | `python3 tools/make_py_vault.py` |
| `flight/` | **Claude's own flight control** (2026-11-07) - read [`flight/README.md`](flight/README.md), the flight manual: `claude_flight.py` moves the ArcGIS Earth camera through the local API - `read`, `turn [deg]`, `orbit [deg]`, `glide [m] [climb ft]`, `return [m] [drop ft]`, `driveby [m] [low ft]`, `downtown` (goto: point to point), `gaterun` (adds World Gates v21, flies to the JAX ATL gate, lines up, jumps to Atlanta), `tour` (multi-stop: JAX gate home, downtown, chopper orbit, neighbourhood, drive-by, climb-out) (circles the spot under the screen centre, eased, lets go if anyone else moves the camera), logs to `flight_test_log.txt`; `Claude_Flight_Test.bat` launcher (brings ArcGIS Earth to the front). Proven on Jim's PC through the linked session (CLAUDE.md 2c). Seed of the autopilot / screen saver. | `py claude_flight.py orbit 360` |
| `p25/` | P25 GPS tracker groundwork (2026-11-07): `P25_Discriminator_Capture_Settings.pdf` (Audacity/Windows settings, capture plan, log sheet) and its generator `make_capture_settings_pdf.py`. Plan in CLAUDE.md section 6. | `py make_capture_settings_pdf.py` |
| `preview_view.py` | Draws what a KMZ looks like in ArcGIS Earth from a camera pose (pinhole model fitted to Jim's screenshots, 5 px rms) and lists overlapping labels - check gate packs and sky objects before Jim flies them. | `from preview_view import load_kmz, render, overlaps` |
| `graphics/earthstick_getting_started.html` | Source of the 'Fly the real world in 7 steps' pictogram (own SVG icons, no logos). Edit the HTML, then render with Playwright at 1600x1000, deviceScaleFactor 2 -> EarthStick `images/earthstick_getting_started_full.png` (3200x2000) and a 1600x1000 copy. | open in Playwright, screenshot |
| `graphics/earthstick_whats_in_the_folder.html` | Source of the EarthStick 'What's in the folder?' sheet (hand-made, 1600x1100). Render like the 7-steps picture -> EarthStick `images/earthstick_whats_in_the_folder(.png/_full.png)`. | open in Playwright, screenshot |
| `graphics/make_zip_sheets.py` | 'What's in the zip' sheets for the other nine packages (Jim, 2026-11-04). Facts per card live in `SHEETS`; update the card list whenever a zip's contents change. Dashed green cards = what the tool makes, not in the zip. Copies live in each repo's images/assets folder as `<tool>_whats_in_the_zip(.png/_full.png)`, linked under every download heading, on the front page and in each manual (PDFs rebuilt). | `python3 make_zip_sheets.py OUTDIR [keys...]` |

Which PDF comes from which manual, the page layout standard, and the video for each tool are listed in [`../CLAUDE.md`](../CLAUDE.md) (section 2a).
