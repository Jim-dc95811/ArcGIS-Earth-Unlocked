Fly the real world in 7 steps

ArcGIS Earth + EarthStick + World Gates  ·  everything here is free except the joystick
1
Get ArcGIS Earth
Free 3D globe from Esri.
Download the Windows desktop version and install it.
2
Turn on the API
In ArcGIS Earth: Settings > Advanced > turn on Automation API.
This lets EarthStick fly the camera.
3
Get Python 3
Free from python.org.
When the installer asks, tick "Add python.exe to PATH".
4
Set up the joystick
Download and install the driver from support.thrustmaster.com (TCA Sidestick X Airbus Edition), then plug it in by USB.
5
Download EarthStick
Get the zip from the GitHub page.
Right-click it > Extract All.
6
Start it
Double-click EarthStick.bat.
Or run Make_Taskbar_Shortcut once for a one-click taskbar button.
7
Open the KMZ file
Drag Gates\World_Gates file onto the ArcGIS Earth map so you can see the rings.
GO
Fly through!
Line up on the gold side, match the height under the name, and fly through the middle.
