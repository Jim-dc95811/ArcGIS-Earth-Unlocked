What's in the EarthStick folder?

After you Extract All the zip, you get just four things. Here is what each one is for.
START HERE · DOUBLE-CLICK
Fly_ArcGIS_Earth.bat
The "go" button
Double-click it: it gets the PC ready (installs Python if it is missing), opens ArcGIS Earth, checks it is answering, then starts EarthStick. The one you use every time.
KEEP IT HERE · DRAG TO SEE
Gates
The World Gates
EarthStick reads this folder when it starts, so fly-throughs work. To see the gates, drag the file inside it onto the ArcGIS Earth map (or Open KMZ file).
DRAG ONTO THE MAP
City_Beacons
Shortcuts to 9 cities
Red "Go to ..." markers for Jacksonville, Atlanta, New York, London, Paris, Rome, Tokyo, Sydney and Rio. Drag one onto the map, then double-click it to jump straight there.
LEAVE IT ALONE
System Files
The engine room
The program and its helpers - you never need to open it. Inside: Ready_To_Fly.ps1 readies the PC; gate_dropper.py draws dropped gates; Make_Taskbar_Shortcut.bat = taskbar button.
Keep all four together in one folder. Don't move one out on its own.
Your own gates go in the Gates folder: World Gate Maker gates (restart EarthStick to arm them) and gates you drop with the trigger (armed at once).
Blue Windows warning? Click More info, then Run anyway. It only asks the first time.
