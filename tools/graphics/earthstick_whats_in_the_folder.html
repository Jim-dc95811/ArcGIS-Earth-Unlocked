What's in the EarthStick folder?

After you Extract All the zip, you get these six things. Here is what each one is for.
START HERE · DOUBLE-CLICK
Fly_ArcGIS_Earth.bat
The "go" button
Double-click it and it opens ArcGIS Earth and EarthStick for you, in the right order. This is the one you will use every time.
DOUBLE-CLICK ONCE
Make_Taskbar_Shortcut.bat
Makes a button for you
Run it one time. It puts an "ArcGIS Earth Flight" icon on your desktop. Right-click that icon, Show more options, Pin to taskbar - now it's one click forever.
DOUBLE-CLICK (OTHER WAY)
EarthStick.bat
Starts just the joystick part
Use it if ArcGIS Earth is already open. A black window appears - that is EarthStick working. Leave it open while you fly; close it when you're done.
LEAVE IT ALONE
EarthStick.py
The program itself
This is the brains. The .bat files run it for you, so you never open it. On some PCs it looks like a blank page - that's normal. Just keep it in this folder.
KEEP IT HERE · DRAG TO SEE
Gates
The golden rings (World Gates)
EarthStick reads this folder when it starts, so fly-throughs work. To see the rings, drag the file inside it onto the ArcGIS Earth map (or Open KMZ file).
DRAG ONTO THE MAP
City_Beacons
Shortcuts to 9 cities
Red "Go to ..." markers for Jacksonville, Atlanta, New York, London, Paris, Rome, Tokyo, Sydney and Rio. Drag one onto the map, then double-click it to jump straight there.
Keep all six together in one folder. Don't move one file out on its own.
A 7th file may appear after the first start: ArcGIS_Earth_path.txt. It just remembers where ArcGIS Earth is. Leave it.
Blue Windows warning? Click More info, then Run anyway. It only asks the first time.
