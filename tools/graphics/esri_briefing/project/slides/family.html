ArcGIS Earth Unlocked

Ten tools across eight public GitHub projects, all downloadable in one zip from the front door site. Every picture is a real screen from field testing (the RMC tester tile is drawn from its own console output). Architecture in one line: foundation maps say what the world looks like (TPKX); operational data says what databases know about it (Parcel100, PointLayer); EarthStick is how you move through it; Object Factory places meaning in it; ArcGIS Earth renders all of it.
