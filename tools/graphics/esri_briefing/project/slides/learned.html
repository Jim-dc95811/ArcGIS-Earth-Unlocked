ArcGIS Earth Unlocked

11

All measured on ArcGIS Earth Desktop 3.0.1.4805 during the build. The popup finding is the big positive: a KML popup is a built-in browser, so an object can show a live picture or POST a drawing to the Automation API on localhost:8000. The negatives each cost a feature: City Beacons land overhead because LookAt is ignored; an attitude beam failed because graphics drape on the terrain and drawings flash a cyan highlight every time they are re-added. Eye altitude is measured from sea level, and KML text and icons stay a fixed size on screen.
