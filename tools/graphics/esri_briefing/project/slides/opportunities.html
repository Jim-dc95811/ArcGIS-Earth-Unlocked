Each suggestion comes from a workaround we had to build. 1: EarthStick exists because only the SpaceMouse is supported. 2: City Beacons would frame a landmark instead of landing overhead. 3: would unlock live sky tracks, moving objects and an aiming beam. 4: EarthStick draws its own readout because full screen hides eye altitude. 5: mb2tpkx exists because ArcGIS Earth cannot open the MBTiles that QGIS makes.
