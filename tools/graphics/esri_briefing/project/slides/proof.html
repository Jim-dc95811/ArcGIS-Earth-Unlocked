Consistency is the point of this slide. Every package opens the same way: one obvious .bat to double-click, the PDF manual right next to it starting with an installation box, a System Files folder, and a 'What's in the zip' sheet explaining every file. Python and its libraries install themselves, visibly, with no admin rights and nothing silent (Microsoft Defender clean). In November 2026 every tool went through a re-hardening pass to 2.1: findings ranked, fixes tested against the previous release byte for byte, then live-tested in ArcGIS Earth before release. A file audit found all 63 copies of the 16 current programs identical everywhere they are published. The Shorts are real flights: Claude drives the camera through ArcGIS Earth's local Automation API on Jim's PC - Babel to the Shard flies from Bruegel's crane (1563) in one picture world to the cranes beside the Shard in another, 60 miles away on the ocean.
